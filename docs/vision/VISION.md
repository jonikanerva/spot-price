## Vision statement

Spot Price is a simple web service that calculates the user's true total electricity price and finds the cheapest contiguous time window — providing home automation systems (Home Assistant, etc.) an easy REST API for electricity price optimization.

## Product thesis

Many Finnish households use spot-priced electricity contracts but optimization remains manual. By combining user-specific contract terms (margin, transfer fees, taxes, day/night split) with Nordpool spot data and exposing a simple API, the service enables automatic load shifting — EV charging, water heating, washing machines, etc. move to the cheapest time slot without manual monitoring.

## Target users

- Home automation enthusiasts (Home Assistant, Node-RED, etc.)
- Finnish households on spot-priced electricity contracts
- Audience size: small community, tens of users, non-commercial

## Core capabilities (MVP)

1. **Signup / login** — username and password
2. **Electricity contract settings** — margin %, day/night transfer prices, electricity tax, night-rate hours, timezone
3. **Spot price ingestion** — Finnish prices fetched from a free public source and stored in the database, updated once daily (~14:15 EET)
4. **Total price chart** — web UI displays the user's actual total price as a time series
5. **REST API: price now** — returns the user's current total price (spot + margin + transfer + tax)
6. **REST API: cheapest window** — parameter: duration in minutes (e.g. 180), returns the cheapest contiguous future window of that length with start time and average price

## API authentication

- Static API key generated by the user in settings
- Passed as a header (`Authorization: Bearer <api-key>`)
- Simple and Home Assistant compatible

## Non-negotiable product outcomes

- Total price is always correct: spot + margin + correct transfer rate (day/night) + electricity tax + VAT
- Cheapest window calculation returns the truly optimal result, not an approximation
- API responds in under 200ms under typical load
- Spot prices update reliably every day without manual intervention

## UX north star

Simple, functional, reliable. The user configures contract details once, and automation handles the rest. The web UI is clean but secondary — the API is the primary product.

## Interaction and accessibility principles

- Web UI works on mobile and desktop
- Settings are clear and validated (no way to enter contradictory values)
- API responses are consistent JSON structures, well-documented

## Engineering doctrine

- **Stack:** TypeScript + Node.js
- **Database:** SQLite (simple, no separate server process)
- **Deployment:** Railway.com
- **Architecture:** Monolith — one service, one database, one deploy
- **Geography:** Finland (FI) first, architecture allows adding Nordpool areas later
- **Testing:** Total price and cheapest window calculations are critical — tested thoroughly
- **Spot data source:** Free public API (alternatives evaluated during research phase)

## Decision principles

1. Simplicity over features: MVP first, extend as needed.
2. Correctness over speed: price calculation is always exact, even at a minor performance cost.
3. API first: the REST API is the primary product, web UI is a convenience layer.
4. Reliability over polish: spot data updates and API responses always work.
5. Reversible delivery: small milestones and safe rollback by default.

## Success signals

- Cheapest window calculation returns provably optimal results across all tested datasets
- Home Assistant integration works with API key without custom components
- Spot prices update automatically for 30 consecutive days without errors
- A user can configure contract details and create an API key in under 5 minutes

## Out of scope (MVP)

- Multi-area Nordpool support (architecture allows it, not implemented yet)
- Electricity consumption tracking or forecasting
- Push notifications
- Payment features or commercial use
- Mobile application
